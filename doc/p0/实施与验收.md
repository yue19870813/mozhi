# P0 macOS 技术验证

## 范围与状态

P0 交付最小 macOS 应用、可复现样本和工程证据。**不等同于 P1 MVP，也不代表四端路线已冻结。**

实现：Tauri 2 + React + TypeScript + CodeMirror 6；受限本地文件访问；SQLite trigram 搜索；临时 libgit2 集成样本；Cytoscape 合成图谱；人工中文输入长文页；macOS CI。npm 和 Cargo 锁文件锁定依赖。

核心暂集中在 `crates/core` 的独立模块，后续按技术方案拆成 vault-fs、index、git-sync 等 crate。尚未引入无实现的空包。文档统一放入用户指定的 `doc/`。

## 可复现测量

```sh
npm ci
npm run build
npm test
cargo test --workspace --locked
cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo run --release -p mozhi-core --bin p0-probe -- 10000 > /tmp/mozhi-p0.json
npm run tauri -- build --bundles app
```

搜索样本在临时目录生成 10000 篇、每篇约 5 KB 中文 Markdown，测量建索引、数据库体积、每条查询预热后 25 轮的 p50/p95。查询覆盖一字、二字、多字、英文、混排标点、不存在的词及 FTS 特殊符号。每次最多返回 50 条；短查询的最坏情况需要扫描整个限定目录，不能把 LIMIT 50 当作扫描条数上限。当前仅接收最多 10000 篇库，短词 UI 标明扫描策略；目录参数由后端查询接口支持。

Git 样本仅使用临时 bare 仓库和两个克隆，验证二进制附件和中文路径、快进、分叉合并、双亲提交、非快进推送拒绝及三方冲突内容可取回。**不调用系统 git、不启用外部凭据助手、不连接远程服务，不对用户笔记库执行提交。** HTTPS 编译支持不等同于 TLS/Token 真连接验收。

图谱：技术验证 → 图谱样本，依次选择三档数据。记录初始化耗时、力导向布局耗时、缩放帧率 JSON。缩放测量为 requestAnimationFrame + 脚本平移缩放，最多 180 帧或 15 秒，前台运行；它是交互帧间隔样本，不是 GPU 精确耗时。布局为主线程可分批运行的 cose，150 次迭代；停止按钮可中止。浏览器与 WKWebView 测量必须分别标注。P0 不生成真实笔记关系，也不把合成图谱正确性视作链接解析验收。

## 数据与安全边界

- 只有系统目录选择器可改变授权根目录；JS 仅传相对路径。隐藏路径、非 Markdown、绝对路径、`..` 和符号链接拒绝读写。
- 已有 UTF-8 文件按原文加载；单篇上限 2 MiB。无法读取的文件在打开库时显示跳过清单。
- 同目录临时文件、写入同步、哈希复核、原子替换；恢复副本位于应用私有目录，成功保存后也保留最后版本。
- 保存冲突时保留草稿、停止切换；用户可重新读取磁盘后恢复草稿再协调。关闭窗口等待保存，失败时保留窗口。
- 索引更新失败不把已落盘结果误报为未保存，显示重建提示。重新打开库执行全量重建。
- 无文件监听、跨进程文件锁、自动前台核对或恢复副本自动清理；检查后到替换前仍有极短的外部写入竞态，P1 必须完善。
- 恢复草稿短延迟写入，强杀或掉电可能丢失最近 250 ms 输入；系统 WebView 生命周期必须实测。
- CSP 禁止脚本、iframe 与外部图片；Markdown 原始 HTML 忽略，外链无执行入口，本地链接仅在现有笔记列表内打开。
- P0 不存 Token，不提供远程连接界面；应用未签名公证，不能作为发布包。

## P0 决策门槛

1. libgit2 本地流程验证后仍需补全 HTTPS 适配与四端认证测试，才能确认 Git 路线。
2. CodeMirror macOS / 手机中文 IME 由真实操作者完成，未完成前仅为候选。
3. Cytoscape 的性能预算以 WKWebView 和移动真机记录为准；若不满足，减少显示预算并比较 WebGL 引擎。
4. trigram + 短词扫描仅在本次数据规模下作为候选；超过 1 万篇、结果全量排序或更复杂查询需补充索引。

上述未验收项是进入后续阶段的显式条件，不能将工程构建通过写作所有 P0 门槛通过。

## 本机实测（2026-09-21）

设备：MacBook Pro Mac15,3 / Apple M3 8 核 / 16 GB，macOS 26.5.2（25F84），aarch64，Rust 1.97.1，Node 22.23.1。测试时同时进行工程编译，属于有并行负载的开发环境；不是专门隔离的性能实验。

原始记录：[macos-rust-report.json](macos-rust-report.json)。Release、10000 篇、约 5150 字节/篇，建索引 **1014.5 ms**，数据库 **78,995,456 字节**。

| 查询 | 策略 | 热查询 p95（ms） |
|---|---|---:|
| 知 | 短词字面量扫描 | 173.88 |
| 图谱 | 短词字面量扫描 | 187.04 |
| 知识图谱 | trigram | 5.27 |
| Markdown | trigram | 41.94 |
| alpha-beta | trigram | 4.03 |
| 预算、计划 | trigram | 103.17 |
| 不存在 | trigram | 0.09 |
| %（无命中） | 短词字面量扫描 | **310.60** |

常见查询满足本轮 300 ms 目标，无命中的单字符 `%` 超过目标，说明短词扫描不是可无限扩展的最终方案。P1 前应增加无命中短词压力样本、独立进程测量，并评估短词倒排索引；本轮不冻结最终数据库设计。

libgit2 1.9.7，本地样本全部通过，总耗时 **242.63 ms**；HTTPS feature 已编译，网络认证未验收。

自动检查：前端 3 项测试、Rust workspace 4 项集成测试、TypeScript 构建、`cargo check`、Clippy（警告视为错误）与 rustfmt 通过。Vitest 升至 4.1.11，安装审计显示 0 个已知漏洞。`.npmrc` 使用 `legacy-peer-deps` 避开 npm 10 对 Vitest 可选浏览器 provider 的解析崩溃，未引入这些不使用的 provider。

macOS release 应用已成功构建：`target/release/bundle/macos/墨知.app`。`npm ci --offline` 从锁文件重新安装及前端测试再次通过。

原生启动检查：已通过 macOS 应用自动化启动 release 包，WKWebView 地址为 `tauri://localhost`，界面显示 3 篇本地示例、正文与安全预览，以及「已保存到本机」状态；说明 Tauri IPC、Rust 授权示例库初始化与文件读取链路可运行。此检查不代表 IME、图谱帧率或关闭恢复已验收。

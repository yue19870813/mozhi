# 界面语言切换

- 在「设置 → 外观 → 语言」选择简体中文、繁體中文、English 或日本語，立即生效并保存在本机应用偏好中。
- 首次启动读取系统首选界面语言：`zh-Hant`、`zh-TW`、`zh-HK`、`zh-MO` 使用 `zh-TW`，其他 `zh-*` 使用 `zh-CN`（显式 `zh-Hans` 优先），`ja-*` 使用 `ja`，其它使用 `en`。已有有效选择优先，不随系统语言变化。
- macOS、Windows 使用 `sys-locale` 读取系统首选语言；浏览器演示使用 `navigator.language`。原生读取失败时回退到 WebView 的语言。
- 导航、设置、操作提示、常见错误、辅助标签、原生文件选择和凭据窗口支持四种语言；日期使用当前界面语言格式。
- 笔记正文、已有文件名、用户笔记标题与路径、Git 历史、AI 生成内容不因界面切换而改写。演示笔记正文保持原始样本。
- 语言切换不会重建编辑器或清除笔记草稿、聊天和笔记库配置；原生更新或偏好保存失败时保留原选择并显示错误。

## 验证

- Vitest：系统语言归一化、首次保存、手动选择优先、无效与不可访问偏好、四语显示和用户内容保护、静态字典覆盖、已有提示切换。
- 既有 Playwright 验证覆盖原三语切换、刷新保留、深浅主题与 1280/480 px 窗口；新增繁体中文的视觉和原生弹窗仍需人工验收。
- 繁体中文回归：系统地区与文字脚本识别、偏好持久化、全词表覆盖、提示跨语言切换，以及用户标题、路径与插值内容不转换。
- 前端构建与测试、Rust 工作区测试、Clippy、格式检查通过。
- Windows 凭据模块通过 `x86_64-pc-windows-msvc` 交叉编译检查。
- 当前验证环境为 macOS；Windows 原生窗口与系统语言读取仍需对应平台运行验收。

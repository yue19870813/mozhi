# 同步交互优化验收

## 行为

手动和自动同步使用独立同步状态，不再将整个网络请求包在前端全局忙碌状态中。同步之前保存当前草稿，期间可以切换模块、浏览笔记、搜索和查看预览。同步时笔记只读，禁止修改文件、重复同步和切换笔记库；完成后恢复编辑。保存前置阶段和最终刷新阶段暂时进入忙碌状态，避免导航与草稿刷新交错。

Rust 同步继续在阻塞工作线程执行。同步任务复制路径、配置和原生凭据快照，然后释放应用状态互斥锁。获取和推送阶段释放笔记库文件锁；本地提交、合并及未完成同步恢复保持独占。读取使用共享锁，文件合并时等待后继续。独立同步锁在整个任务期间禁止其他窗口修改同一笔记库，同步状态保护会在成功或错误退出时恢复。

## 验证

- 前端构建与 43 项测试通过。
- Rust 工作区测试、Clippy、格式检查及 diff 检查通过。
- 回归测试验证同步中读取可用、修改拒绝、状态退出后恢复、跨窗口写入拒绝及合并锁释放后读请求继续。
- 现有 Git 回归测试仍覆盖合并、冲突、恢复和外部修改保护；增加获取前后与推送的阶段顺序断言。
- Playwright 使用合成笔记和模拟原生接口挂起同步，验证等待期间可以打开另一篇笔记、编辑和重复同步受限、完成后编辑恢复。深浅主题与 1280px/480px 窗口检查通过。

没有连接真实远端 Git 或操作用户笔记库。当前验证环境为 macOS，Windows 真机和真实慢速网络仍需后续运行验收。电脑插件的 Chrome 连接返回认证错误，内置浏览器拒绝访问本地测试 URL，因此界面验收使用独立开发测试浏览器。

# AI 助理首版验收

## 实现范围

- 桌面应用的笔记库问答、当前或多篇笔记总结、编辑后保存生成笔记。
- 应用级 OpenAI 兼容模型配置，独立系统凭据条目和原生密码输入。
- 本地关键词检索与手动补选，最多 10 篇、24,000 个参考字符；单篇取开头最多 6,000 个字符，预览展示实际文本与截取标记。
- 默认逐次预览确认；自动发送授权按笔记库和服务配置版本绑定，可撤销。
- 流式 Markdown、实际来源跳转、停止生成、清空和手动重试；会话只保留在内存中。
- 新笔记使用独立 UUID、现有路径边界检查和禁止覆盖的原子写入；索引更新失败不将已成功保存的文件报告为保存失败。

## 自动验证

在 macOS 开发环境执行：

```sh
npm run build
npm test
cargo test --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo fmt --all --check
git diff --check
```

前端 43 项测试及 Rust 工作区 41 项测试通过。新增覆盖包括来源引用过滤、远程图片和可执行 HTML 拒绝、上下文数量与字符上限、隐藏路径拒绝、内容变化检测、生成路径穿越、同名拒绝、链接拒绝、缺失目录写入失败以及 LF/CRLF 模型元数据剥离。

模拟本机 HTTP 服务验证路径前缀保留、流式 Unicode 解析、认证失败、限流、超时、取消、重定向拒绝及错误消息不包含凭据或服务响应正文。授权测试覆盖撤销、服务变化及配置版本变化；运行时测试覆盖切库取消和会话索引隔离。

Playwright 使用浏览器演示界面检查深浅主题、1280px 和 480px 窗口、模式切换及设置入口，未发现横向溢出或页面异常。测试仅使用合成数据，不读取系统凭据，也不向真实模型发送笔记。

另使用模拟原生 IPC 的组件界面测试验证手动补选、发送前确认、来源跳转、目录选择、编辑生成内容后保存新笔记及清空对话。此测试验证前端流程，不替代真实 Tauri 与模型端到端验收。

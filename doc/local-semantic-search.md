# 内置本地语义检索

设置 → AI 模型 → 本地语义检索。首次下载固定版本的 INT8 多语言 MiniLM 模型和分词器，约 129 MiB。无需 Ollama、Python 或独立服务。默认未下载、未启用；模型文件不随安装包分发。官方 Hugging Face 下载源不可达时，用户可以明确选择 hf-mirror.com。下载只请求固定模型文件，不发送笔记、API Key 或系统凭据；所有文件使用固定大小和 SHA-256 校验，HTTPS 重定向不得降级到 HTTP，临时文件仅在校验完成后替换正式文件。

## 数据路径

- 本地 CPU 推理使用 FastEmbed / ONNX Runtime，最多两个推理线程，每批八个片段。
- 模型：sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2，Xenova ONNX INT8 转换，固定 revision `2c4055b12046f11709e9df2c122e59ffbdc2f900`。384 维，mean pooling；模型及分词器校验清单在 `src-tauri/src/semantic.rs`。
- 按段落边界切分 Markdown 正文（不含 front matter），先按 Unicode 字符划分，再用模型分词器检测溢出并递归拆分。避免长中文段落被静默截断。正文字符范围为去掉 front matter 后的范围。
- 模型存储在应用私有 `embedding-models/<model-id>`，每库索引在私有 `vaults/<vault-id>/semantic.db`；均不进入 Git。
- SQLite WAL、每篇笔记事务更新，以完整文件哈希检测变化。取消或失败保留已完成笔记，点击更新继续；重建索引清空可重建的向量数据，不改变笔记。
- 启用后每 20 秒在后台扫描当前库的新增、修改、删除及同步后变化；错误或用户停止后暂停自动索引，手动更新恢复。
- 推理和模型下载期间不持有笔记库锁；写入索引前重新验证当前笔记库和文件哈希。切库取消当前索引，已完成的索引留在原库。

## 问答与隐私

只在笔记库问答中使用语义检索，其他 AI 模式保持原有上下文规则。问题在本机向量化，与关键词检索合并；同篇笔记优先使用语义命中的正文范围，来源去重并编号，最多 10 篇、24,000 个字符。发送前再次检查来源哈希；索引过期的片段不进入云端请求。现有发送预览、服务授权、请求取消、云端流式输出及来源链接全部复用。

模型没有工具或写文件能力，索引建立时笔记不离开本机。问答阶段的问题、选定上下文和已有问答会话仍可能发送给配置的云端服务，依照现有授权规则。

## 限制

- 首版仅 Markdown 文本，不处理 PDF、Word 或附件；全库总结不在本次范围。
- 相似度检索使用本地精确余弦扫描，适合个人笔记库；大型索引后续可迁移 ANN，而不改变接口。
- 后台更新有最多一个扫描周期的延迟；新索引建立前仍能关键词问答。实际中英日召回质量须使用用户选定的非敏感样本进一步评估。
- CPU 推理使安装包增加 ONNX 运行库体积；不同平台 Release CI 必须完成链接、签名与安装后的离线加载验收。

## 许可

模型上游为 Apache-2.0；下载完成后在模型目录写入 LICENSE 和来源 NOTICE。FastEmbed 为 Apache-2.0，Rust ort 绑定为 MIT/Apache-2.0，ONNX Runtime 为 MIT。运行库和模型许可文本在 `src-tauri/licenses`，静态链接时一并嵌入应用可查询的许可信息。

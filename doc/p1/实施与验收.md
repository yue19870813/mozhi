# P1 macOS MVP 实施与验收

日期：2026-09-21。状态：**MVP 候选实现，等待真实远程与人工验收；不是所有 P1 条件已通过。**

## 已实施

| 模块 | 行为 |
|---|---|
| 笔记目录 | UUID 新笔记、目录树、创建、移动、删除；跨平台保留名/大小写/NFC 校验；拒绝路径穿越与符号链接 |
| 多文件操作 | Markdown/Wiki 入站引用与移动笔记的出站路径改写；保留链接标题、Wiki 别名和 front matter；先写恢复副本与操作日志 |
| 恢复 | 中断或已完成操作的副本导出到库内新目录，不覆盖后来修改；草稿仍存应用私有目录 |
| 编辑 | CodeMirror 自动保存、切换前刷新、关闭等待保存、冲突只读与入口；最近笔记库恢复；深浅主题 |
| 附件 | 系统选择器导入 PNG/JPEG/GIF/WebP，签名检测、10 MiB 限制，复制成功后插引用；Rust 受限读取为 data URL；重命名图片更新引用 |
| 搜索 | FTS5 trigram + 一字/二字倒排补充索引；标签数组、目录、文件名组合；`tag:`/`path:`；最多 100 条 |
| 关系 | pulldown-cmark 源区间解析 Markdown；排除代码/HTML/图片节点；Wiki 根目录/当前目录/全库唯一规则，缺失与歧义区分；重复 ID 提示 |
| 图谱 | 当前库真实关系、方向和聚合计数；局部 BFS 一/两跳；TAG/目录/关键词/孤立筛选；双击打开；布局停止；当前/完整 PNG 导出（4096 像素上限） |
| Git | libgit2 HTTPS 克隆、固定分支、本地提交、fetch、快进/三方合并、推送；最多 3 次非快进重试；未知文件变更、外部 merge/rebase/锁暂停 |
| 凭据 | 原生 NSSecureTextField 输入，Keychain 按 URL 与用户名隔离；JS 只得到成功状态，Token 不进入 IPC |
| 冲突 | 祖先/本地/远程/手动结果；删除与编辑；二进制选单方/保留双方；原附件引用指向本地、远程副本以确定性后缀保存 |
| 同步恢复 | 私有 pending 记录保留两端提交和目标提交；HEAD/索引/工作区核对；检出后、引用更新前中断可继续；外部改动时停止而非强制覆盖 |
| 历史与导出 | 最近 50 次单篇变更（最多扫描 500 提交）；恢复作为当前修改；库 ZIP 导出，不包含 .git/隐藏私有文件 |
| 核对与索引 | 启动、手动、前台增量核对；前台每 5 秒元数据轮询；按内容哈希更新索引；损坏 SQLite 隔离重建，保留草稿 |
| IPC | 活动 vaultId 校验避免旧库请求写入新库；应用内串行锁、fs2 进程锁；同步阶段事件含 vaultId/taskId/sequence |

## 1 万篇实测

设备沿用 P0：Apple M3 / 16 GB / macOS 26.5.2，release，10000 篇约 5150 字节，预热后每查询 25 轮。原始记录：[macos-rust-report.json](macos-rust-report.json)。

| 查询 | P1 p95 ms |
|---|---:|
| 知 | 25.52 |
| 图谱 | 25.89 |
| 知识图谱 | 0.41 |
| Markdown | 34.23 |
| 预算、计划 | 30.38 |
| %（无命中） | 23.90 |

建索引约 7.42 秒，SQLite 约 239.9 MB。补充短词索引显著改善 P0 的 311 ms 无命中短词，但增加存储与建库时间。P1 每次最多 100 条，P0 为 50 条；排序/摘要实现也不同，不能视为严格等条件对比。当前摘要截取正文开头，尚未实现命中片段高亮。

## 仍待完成的验收与边界

- GitHub/Gitee/自建 Git 的实际 Token、TLS、分支保护和限流验收尚未执行。本地测试不需要也没有使用用户的远程凭据。
- 系统拼音组合输入、100 KB 长文输入、真实掉电/强杀、多进程与外部 Git 并发故障注入仍待人工完成。
- 图谱已接真实数据，但 WKWebView 的 1000/3000 性能、导出图片裁切和可访问性尚待完整实测。未实现布局位置缓存、图谱空心缺失节点和快捷键命令面板。
- 当前使用 5 秒元数据轮询与前台全内容核对。原生事件监听依赖下载遭自动审批系统解析失败而拒绝，未绕过；轮询不依赖该包。元数据完全不变的外部编辑会在前台/手动核对时发现。
- 同步期间编辑器暂时只读；未提供前台定时自动同步（方案为可选）。长耗时建库/网络同步暂无用户取消入口。
- 多文件改写失败时可从完整副本恢复到新目录，尚无自动回滚；不覆盖新修改。检查后到替换前仍可能遇到外部进程写入竞态，不能防御恶意本机进程。
- 核心仍以独立模块组织在 `crates/core`，未为了目录形式拆分多个 crate；持久化关系元数据为 SQLite JSON，图关系在查询时解析，当前 1 万篇预算内使用。
- 首版长期凭据仅实现 macOS；未验证 Windows/Android/iOS。发布签名、公证和自动更新属于后续发布阶段。

以上限制需要在宣布 P1 正式验收或进入跨平台发布前处理，不将候选版描述为全部技术方案已完成。
